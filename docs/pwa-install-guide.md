# Guia de instalação do PWA Coletaqui Araçoiaba

Este guia explica como instalar o Coletaqui Araçoiaba como aplicativo no celular ou computador.

O Coletaqui é um PWA. Isso significa que ele abre pelo navegador, mas pode ser instalado com aparência de app, ficando com ícone na tela inicial e sem a barra de endereço do navegador quando aberto pelo atalho instalado.

Endereço do app:

```text
https://coletaquiaracoiaba.com.br
```

## Android

Use de preferência o Google Chrome.

1. Abra o Chrome.
2. Acesse:

```text
https://coletaquiaracoiaba.com.br
```

3. Toque no menu de três pontos no canto superior direito.
4. Toque em **Instalar app**.
5. Confirme em **Instalar**.
6. Abra o app pelo ícone **Coletaqui Araçoiaba** na tela inicial.

Se aparecer apenas **Adicionar à tela inicial**, toque nessa opção. Em alguns aparelhos o nome muda, mas o resultado esperado é criar o ícone do aplicativo.

## iPhone e iPad

Use o Safari.

1. Abra o Safari.
2. Acesse:

```text
https://coletaquiaracoiaba.com.br
```

3. Toque no botão de compartilhar.
4. Toque em **Adicionar à Tela de Início**.
5. Confirme o nome **Coletaqui Araçoiaba**.
6. Toque em **Adicionar**.
7. Abra o app pelo ícone criado na tela inicial.

No iPhone, a instalação de PWA deve ser feita pelo Safari. Outros navegadores podem abrir o site normalmente, mas podem não oferecer a instalação correta.

## Computador

Use de preferência Google Chrome ou Microsoft Edge.

1. Abra o navegador.
2. Acesse:

```text
https://coletaquiaracoiaba.com.br
```

3. Procure o ícone de instalação na barra de endereço.
4. Clique em **Instalar**.
5. Abra o Coletaqui pelo atalho criado no computador.

Se o navegador mostrar a opção **Criar atalho**, marque **Abrir como janela** quando essa opção aparecer.

## Como saber se instalou corretamente

O app foi instalado corretamente quando:

- aparece um ícone do Coletaqui na tela inicial ou área de trabalho;
- ao abrir pelo ícone, a tela fica com aparência de aplicativo;
- a barra de endereço do navegador não aparece;
- o app continua abrindo em tela própria mesmo após fechar e abrir novamente.

## Problemas comuns

### Não apareceu a opção de instalar

Atualize a página e tente novamente.

Também verifique se está acessando pelo endereço com HTTPS:

```text
https://coletaquiaracoiaba.com.br
```

No Android, tente pelo Chrome. No iPhone, tente pelo Safari.

### O app abriu com barra de endereço

Isso geralmente acontece quando foi criado apenas um atalho do site, e não uma instalação completa do PWA.

Remova o atalho e instale novamente usando:

- **Instalar app**, no Android ou computador;
- **Adicionar à Tela de Início**, no iPhone pelo Safari;
- **Criar atalho** com **Abrir como janela**, no computador quando essa opção aparecer.

### O app parece estar mostrando uma versão antiga

Feche o app completamente e abra de novo.

Se continuar antigo, abra o site no navegador uma vez e atualize a página. Depois abra novamente pelo ícone instalado.

### Preciso instalar para usar?

Não. O Coletaqui também funciona direto pelo navegador.

A instalação é recomendada porque deixa o acesso mais rápido e com aparência de aplicativo.
